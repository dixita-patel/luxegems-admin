# LuxeGems Admin Panel 💎

The administrative interface for the LuxeGems e-commerce platform.

## Features
- **Dashboard**: Overview of sales and metrics.
- **Product Management**: Add, edit, and delete jewelry products.
- **Order Management**: View and update order status.
- **Customer View**: List registered users.
- **Authentication**: Secure admin login.

## Tech Stack
- React.js + Vite
- Tailwind CSS (Navy & Gold Theme)
- Axios (API Communication)
- Lucide React (Icons)
- React Hot Toast (Notifications)

## Setup
1. `npm install`
2. `npm run dev`

## Configuration
- API URL is set to `http://localhost:5000` in `src/services/api.js`.
